# ⏰ Time-Buddy

**A simple Python application built for learning.**

Time-Buddy is a beginner-friendly Python project that provides time-based greetings and messages according to different situations. It also displays the current time and allows users to interact through a simple terminal interface.

---

## 📌 About the Project

Time-Buddy is a command-line application developed using Python.

The main purpose of this project is to practice Python fundamentals by building a real-world beginner project.

Users can enter different situations such as morning, afternoon, evening, night, sleep, or time to receive appropriate messages.

---

## ✨ Features

- 🌅 Morning Greetings
- ☀️ Afternoon Greetings
- 🌆 Evening Greetings
- 🌙 Night Greetings
- 😴 Sleep Mode
- 🕒 Current Time Display
- 🔄 Continuous Interaction Using While Loop
- ❌ Exit Option
- ⚠️ Invalid Input Handling

---

## 🌤️ Available Situations

| Situation   | Description            | Time         |
| ----------- | ---------------------- | ------------ |
| `morning`   | Morning greetings      | 6 AM – 12 PM |
| `afternoon` | Afternoon wishes       | 12 PM – 6 PM |
| `evening`   | Evening messages       | 6 PM – 8 PM  |
| `night`     | Night greetings        | 8 PM – 11 PM |
| `sleep`     | Sleep mode messages    | 11 PM – 6 AM |
| `time`      | Displays current time  | Anytime      |
| `exit`      | Closes the application | Anytime      |

*Note: These are the application's configured time ranges.*

## 🚀 How to Use

1. Run the Python application.
2. Enter one of the available situations.
3. Get your time-based greeting.
4. Enter `time` to see the current time.
5. Enter `exit` to close the program.

**Example:**

```text
Enter situation (morning/afternoon/evening/night/sleep/time/exit): morning

Good morning!
Have a nice day!
```
